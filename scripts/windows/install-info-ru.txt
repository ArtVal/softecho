SoftEcho — домашний тренажёр речи (офлайн)

После установки прогресс и модель Vosk хранятся в папке данных пользователя
(%APPDATA%\SoftEcho\SoftEcho), а не рядом с программой.

Если Windows покажет SmartScreen («неизвестный издатель»):
1. Нажмите «Подробнее»
2. Затем «Выполнить в любом случае»

Это обычное предупреждение для программ с GitHub без платной подписи кода.
Голос (сборка asr): модель скачивается один раз из Настроек.
